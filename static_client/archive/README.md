# Archived Client Variants

This folder stores legacy client implementations that are no longer maintained.

## Source of truth

- Canonical client: `static_client/client.html`
- Legacy URL compatibility wrappers remain in `static_client/` for old HTML entry points and redirect to `/client.html`.

## Legacy files

- Fullscreen/optimized variants
- Mobile-specific legacy variant
- Split JS optimization experiments
- Projectile optimization experiments

These files are preserved for reference only and should not be used for new changes.
